A make.fun bounty entry for **"One Word, First Thought"** (`u-0xkianno-one-word-first-thought-106abaf8`).

## The word

**borborygmus** — the low rumble of a hungry stomach.

Why it should win: it is surprising (nobody guesses it), vivid (one word calls up a clear sound and a feeling at once), and witty (the word itself rumbles like the thing it names). It was picked over the obvious "petrichor" precisely because a field of 265 entries will be full of petrichors — and byte-identical copies share one rate.

## What it does

`main.ts` validates the entry (exactly one word, 1–24 characters, alphabetic only, not whitespace-only) and writes it to `/output/entry.txt`.

## How to run

Requires Node 22 or later (stdlib only, no network, no external files):

```sh
node main.ts
cat /output/entry.txt
# borborygmus
```
